# Къамыл - калькулятор

Калькулятор длины трубки и расстояний до трёх отверстий къамыля (адыгской продольной флейты) для 12 тональностей от E³ до D#⁴.

- Выберите тональность и введите размеры трубки: внутренний диаметр, толщину стенки, диаметр отверстий.
- Все размеры от места вдува, отверстия - до ближнего края.
- Режьте трубку на 20-30 мм длиннее и подпиливайте низ по тюнеру.

Расчёт откалиброван по экспериментальным замерам (трубка 14/16 мм, отверстия 8 мм, поправка вдува 55,5 мм).

Английская версия: добавьте `#en` к адресу.
